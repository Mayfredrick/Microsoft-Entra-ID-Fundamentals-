# Week 4 Day 2 – Entra Users, Groups & Azure RBAC

### 1. Why are security groups useful?

Groups are useful for managing users because an administrator can assign access and permissions to a group instead of assigning them to individual users. This makes access easier to manage.

### 2. What happened when you removed the user from the group?

When I removed the user from the group, the user was removed from the permissions and access associated with that specific group. The user account was not deleted.

### 3. Why can a user belong to more than one group?

A user can belong to multiple groups based on their job responsibilities and role within an organization. Different groups can provide different access and permissions.

### 4. What is Azure RBAC?

Azure Role-Based Access Control (RBAC) is used to control access to Azure resources by assigning roles to users, groups, or other identities.

### 5. What is the difference between an Entra role and an Azure RBAC role?

An Entra role deals with administrative permissions related to Microsoft Entra ID, while an Azure RBAC role deals with access and permissions to Azure resources.

### 6. What is the purpose of the Reader role?

The Reader role allows a user to view Azure resources but does not allow the user to make changes to those resources.

### 7. What is the purpose of the Contributor role?

The Contributor role allows a user to create and manage Azure resources, but it does not allow the user to assign roles to other users.

### 8. Why is least privilege important?

Administrators should follow the principle of least privilege for security reasons. Users should only receive the access and permissions they need to perform their jobs. Giving users unnecessary access can create security risks.

### 9. Why is group-based access better when possible?

Group-based access is easier to manage because administrators can assign permissions to a group instead of managing each user individually. This can also help reduce mistakes when assigning access.

### 10. What did you learn?

I gained more insight into the different Azure roles and how access can be managed using Access Control (IAM). I also learned more about the differences between the Reader, Contributor, and Owner roles.

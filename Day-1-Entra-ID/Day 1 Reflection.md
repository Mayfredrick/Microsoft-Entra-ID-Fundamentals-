## Day 1 Reflection

### What is Microsoft Entra ID?

Microsoft Entra ID helps authenticate and authorize users in a cloud-based environment.

### What is authentication?

Authentication answers the question, **“Who are you?”** It verifies a user's identity.

### What is authorization?

Authorization determines **what a user is allowed to access or do**.

### What is the difference between authentication and authorization?

Authentication verifies who you are, while authorization determines what you are allowed to access or what actions you are allowed to perform based on your permissions or roles.

### Why are security groups useful?

Security groups allow administrators to manage permissions for a group of users instead of managing each user individually.

### What is least privilege?

Least privilege means giving a user only the minimum permissions needed to perform their job.

### What is the difference between Active Directory and Microsoft Entra ID?

Active Directory is traditionally used in an on-premises or local server environment, while Microsoft Entra ID is a cloud-based identity and access management service.

### How does today's lab connect to the Active Directory lab from Week 2?

The lab connects to my Week 2 Active Directory work because both environments use users and security groups to manage access. The difference is that Active Directory is used in my local server environment, while Microsoft Entra ID is used for cloud-based identity and access.

### What was the most challenging part of today's lab?

The lab was straightforward, and I did not encounter any major challenges.

### What did I learn from today's lab?

I learned how to create security groups and add users to those groups. I also learned how authentication, authorization, and least privilege are used to manage access in a cloud environment.
